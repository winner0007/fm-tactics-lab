# Mac 版本更新记录

## 0.8.1 — 2026-11-13

- “指定游戏位置”始终显示，自动找到游戏后也能更换安装。可选 Steam 游戏库、steamapps、common、游戏文件夹或 fm.app，支持改名文件夹和符号链接；只记住通过完整性检查的位置。
- 找不到目录、磁盘未挂载、安装不完整和引擎未适配分别提示。手动选择失败时不会换用另一处自动发现的游戏；导入、引擎检查或模拟期间不能切换安装。
- 补充换机使用和手动定位说明。查找按当前电脑的用户目录及 Steam 库记录执行，不绑定开发电脑路径；仍需 Apple Silicon、macOS 14+ 和已适配的 FM27 版本。

## 0.8.0 — 2026-11-13

- 实验双方与联赛各队增加指定／随机／原版 AI 战术，支持统一设置和逐队覆盖。新联赛对手默认 AI，我的测试球队默认工作台；旧联赛保留固定战术。复制统一战术保留各队球员和状态。
- 接通 27.0.1.2503222 原版赛前 AI：写入名单和可确认的教练参数，读取生成结果后冻结，再进行比赛。批次一次生成、联赛每个主客对阵一次生成；停止续跑不重抽，快照绑定输入、种子和引擎。缺少或无法唯一确认的教练明确采用原版测试教练参数，不模拟生涯聘任或临场 AI。
- 原始 DAT 2700 可直接导入真实球队、球员池、联赛归属和可确认的主教练；自动查找安装数据库，也可手选目录。未设定球员数据按固定规则补全并保留原值，未加载开档初始化器或编辑补丁，完整排名规则仍需选择。
- “我的测试球队”与编辑球队分开保存。积分榜、球队／球员榜、积分图、逐场成绩及 HTML 报告统一星标与绿色高亮，球员榜可只看本队；报告换标记不改变已运行的配置。
- 更新引擎页的已接入／未接入说明。FMF 导出始终使用当前可见方案，导入后采用指定战术；用户已确认游戏内导入、导出可用。
- 压缩包从干净暂存目录打包，包含应用和使用说明，重新解压检查深层签名，SHA-256 随版本发布。补充百度网盘上传方式，以及下载校验、开发者拦截、解压失败和“已损坏”的处理步骤；无开发者账号，仍不承诺下载免提示。

验证范围见[实测记录](docs/MAC_ENGINE_STATUS.md)。

## 0.7.0 — 2026-11-12

- 每队三套战术，按分钟、比分条件和规则顺序自动切换；通过原版临场指令应用，回读确认位置、角色和指令，保留同场时钟与球员状态。支持开场方案、冷却间隔和条件消失后的回退。
- 普通批次与联赛支持 1–256 路并行，记住上次设置并给本机建议。比赛各自使用独立宿主；停止后保留已完成结果，恢复只补缺失场次，改变并行数不改变种子与对阵。
- 按完整战术比较场均控球、传球、传中、射门、射正、进球、xG，以及传球／传中成功率、射门转化率、有进球场次占比。联赛对手分组同步增加技术统计。
- 新增比分分布、进球时段、原版终场进球与助攻、非点球／点球／乌龙分类、逐场 xG 和切换记录。取消的进球不计入；乌龙球不计入本队射门转化率。图表适配窄窗口，HTML 导出保留相同口径。
- 临场方案按实际生效时间分段，记录累计进失球、xG、控球及每 90 分钟的传递和射门。旧报告没有的事件与统计显示缺失，不补零。
- 完整球队方案升为格式 5，保留三套战术和规则，兼容旧格式；单个 FMF 只交换当前编辑方案，定位球与球员另存完整 JSON。
- 补充战术规则、AI 教练、数据保存和打包说明：教练锁定保护配置，原版 AI 战术生成仍待接入；联赛不推进成长、衰减、伤停累积、退役和转会等生涯流程。
- 应用内置存档读取组件，无需额外安装 Python 或管理员安装。当前无 Apple 开发者账号，采用本机临时签名，未做 Developer ID 公证，网络下载后不能保证无系统提示。

验证：53 项核心检查；8 场单路与 4 路结果逐项一致；双边临场指令、取消补缺、64 场终场事件及传中合计通过。64 场包含 204 个非点球进球、11 个点球和 4 个乌龙球，另覆盖取消进球与红牌的区分。打包应用通过 26 场普通批次、24 场联赛、存档导入与双窗口宽度布局核对。具体范围见[实测记录](docs/MAC_ENGINE_STATUS.md)。

## 0.4 — 2026-11-10

基于上游 [lqf0624/fm-tactics-lab](https://github.com/lqf0624/fm-tactics-lab) v1109.3（`6cb32bf`）新增独立 Mac 客户端。保留上游 Windows 实现与 MIT 许可。

### 原版引擎

- 接通指定 FM27 `27.0.0.2493426` arm64 构建的完整原版插件；初始化 ICU、原生文件系统、模拟资源、xG 模型和比赛线程上下文。
- 使用用户安装包自带测试 PKM，经过反序列化、赛前准备和逐步运行达到自然终场；比分与统计读取自原版对象。
- 支持起始种子及 1 / 5 / 10 / 20 场批次，每场独立进程；校验二进制／输入指纹，支持停止与超时，未完成结果不进入统计。
- 处理上下半场时钟回退，按原版时钟的正向增量绘制累计比赛时间与 xG 曲线。
- 保存球队和球员基础统计，核对规范球员记录与球队合计；球员以原版 ID 标识，未知字段保持为空。

### 战术、阵容和分析

- SwiftUI 双阶段战术板，共用首发，拖动到重叠位置自动换位，支持对照、撤销、重做与自动保存。
- 球员能力分为随机、业余、半职业、职业、享誉国内、洲际、国际；每人每项在区间内独立随机，支持全队、位置及个人设置。
- 球队／球员指令和定位球配置流程：主罚排序、内外旋、左右侧复制、职责优先级、球员排序、替补递补及界外球偏好。
- 手动记录体能、疲劳、磨合、性格与关系；不将未知量换算为虚构的比赛加成。
- 自动发现 Steam 库、应用目录及外置安装位置，找不到后支持手动指定。
- 球队图表、球员累计图表、逐场明细、历史批次和 CSV / JSON 导入导出；兼容上游逐场 CSV。

### 验证

- 34 项核心检查通过。
- 9 场原版引擎回归通过：同种子复跑一致、不同种子结果变化、边界种子正常；缺失安装和取消不生成有效结果。
- 11 类无效／不完整报告检查通过，包括统计合计不一致与错误输入来源。
- 应用内 5 场连续比赛、200 条球员记录、持久化恢复与 3 个真实数据视图通过验证。
- 构建后的应用与两个辅助进程通过本机签名校验。

### 当前范围

Mac 模拟输入仍为游戏自带测试阵容和战术。编辑器中的自定义球员、战术、定位球与状态尚未传入引擎；不支持 Mac 端 `.fm` / `.fmf` 读写。Intel Mac 与其他游戏构建也未适配。工具的能力区间和草图指令不能当作官方 CA 换算或已验证的原生战术字段。

下一步优先实现自定义输入的写入、回读和生效验证。详见 [引擎验证记录](docs/MAC_ENGINE_STATUS.md) 与 [接入路线](docs/PORTING.md)。
