# Mac 使用说明 · v0.6

这版可以把你设置的球员、战术和定位球交给 FM 原版引擎，跑一批比赛或一个联赛，再看完整结果。

## 启动与第一次测试

退出旧版，打开 `dist/FM Tactics Lab 0.6.app`。需要 Apple Silicon、macOS 14+ 和本机 FM27；目前适配 `27.0.0.2493426`。应用暂用本机签名，未做 Developer ID 公证。

更新至 `27.0.1.2503222` 后，存档球队与赛程可以导入，比赛和 FMF 读写暂不能运行。应用会检查当前引擎指纹；旧版历史完赛记录不会被当成新版已适配的证明。

1. 到「引擎与接入」查找游戏。程序会搜索 Steam 库、应用目录和外置磁盘，找不到时再选 `fm.app`。
2. 在编辑页顶部选「普通对战」，分别设置主队和对手。战术页与球员页共用当前选中的球队。
3. 排好首发、角色、指令和定位球，填写种子及场数，点击「运行比赛」。场数可设为 1–2000；种子决定本次比赛的随机过程，复测时可使用相同种子。
4. 到「实验对比 → 测试报告」看双方数据和图表。HTML 适合阅读与分享，CSV 适合表格分析，JSON 保留完整数据。

## 战术和球员怎么设置

有球、无球阵型共用 11 名首发，两阶段位置可分别调整。拖到已占用的位置会换位。可套用 12 种阵型，或用 24 个位置自行组合；右侧角色与指令按位置显示，不适用的选项会锁定。

球员可手填、导入 CSV 或从存档读取。比赛带入首发及名单中前 9 名候补。资料按钮可改身高、体重、年龄、CA、声望和性格，隐藏属性在单独页签中编辑。

随机能力可用于全队、某个位置或一个人：随机 1–20、业余 3–7、半职业 5–10、职业 8–13、享誉国内 11–16、洲际 13–18、国际 15–20。中卫更偏防守和争顶，边路球员更偏速度、盘带和传中；隐藏属性与性格单独随机。档次只是本工具的属性范围，CA 另设。再次随机会替换原属性，可用 ⌘Z 撤销。

定位球包含攻守角球、三类任意球和界外球，共 10 种情形，每种可设 1–3 套套路。任务、使用频率、备用安排、主罚人和队长都可调整。

## 保存阵容与交换游戏战术

在「阵容方案库」填写名称，保存当前球队。球员、候补、属性、性格、双阶段战术、定位球和开赛状态一起保留。重开应用仍可载入，也可复制为新联赛球队，或导出／导入方案 JSON。载入替换当前编辑球队，可撤销；归档文件仍保留，可重新导入。

工作台的「战术文件」可导入和导出 FM27 游戏战术 `.fmf`。导出调用本机原版序列化器，封装后再通过原版读取器逐项核验；不一致则不写出目标文件。保存到游戏的 `tactics` 文件夹后，在游戏战术页面选择载入。导入只替换阵型、角色、职责、心态与指令，保留当前球员、定位球和状态。指定球员盯人按当前对手名单解析，需要核对目标。

与 Windows 原项目一样，战术 FMF 不包含球员属性和定位球套路；完整实验配置请保存到方案库。定位球 FMF 的单独交换尚未适配。

## 自己的球队和联赛是什么关系

**每支联赛球队都有自己的球员、战术和定位球。** 顶部的「普通对战／联赛球队」和球队名称告诉你正在编辑谁。

- 把普通对战球队带进联赛：点击「复制普通对战主队」或「复制普通对战对手」。复制之后两份数据各自保存。
- 修改联赛球队：在该队所在行打开「阵容与属性」或「战术与定位球」。两个入口编辑同一支队，修改自动保存。
- 调整随机球队：可以逐人修改，也可以点「随机本队能力」重新抽取。只影响这一队的属性与性格，名单和战术保留。个人随机在球员页操作。

球队名称在联赛列表改，战术名称在工作台改。返回普通对战后，原来的主队和对手仍在。

「教练与锁定」可以手动指定教练，或选择当前方案中的已有教练。教练与战术分别锁定：锁定战术会阻止改阵、改指令和载入其他战术，仍可调整首发、主罚人、球员属性和开赛状态。当前没有董事会换帅流程，教练姓名本身不参与比赛计算；未锁定也不代表 AI 会自动临场调阵。

## 导入球队并运行联赛

「联赛实验」支持三种来源，可以混用：自己编辑的球队、随机球队、`.fm` 存档球队。也可以用“初始化 JSON”保存和复用一整套联赛设置。

顶部「从 FM 存档导入」可在战术、球员和联赛页打开。先选数据起点，再选球队或完整联赛；单队导入会显示替换目标。整联赛导入前可选择排名规则，导入后继续核对。

导入存档时，先选文件，再搜索单队或选择完整联赛。整联赛导入会保留对阵和日期，从头重赛，不带入旧比分。导入的是一线队球员；战术仍需自己核对。替换现有联赛前会自动备份原配置。

加入 2–40 队后，选择单／双循环、积分和同分排序，或使用英超／西班牙排名预设。可跑 1–100 次赛季，总计最多 20,000 场。点击「运行联赛」后看积分榜、球队场均表现、球员榜和逐场成绩；停止后可以继续。

每次开始实验都会保存当时的球队、规则和种子。**之后改阵容只影响新实验；继续上次实验仍用原配置。** 比赛逐场保存，意外退出后可恢复已完成记录。报告页可打开保存目录，详细格式见 [数据文件与实验记录](docs/DATA_FORMATS.md)。

## 报告能看到什么

普通测试有胜平负、胜率区间、进球与 xG、双方阵容和指令；联赛另有积分排名与多次赛季的名次范围。球员统计包括进球、xG、射门、射正、传球、成功传球和红黄牌，球队另有控球率。未取得的数据用空值表示。

联赛的「面对不同战术的表现」先选分析球队，再按完整战术或双阶段阵型分组，可筛选主客场、合并重复赛季。表格保留场次、胜平负、场均进失球和 xG，以及双方首发平均 CA、对手 CA 范围。相同名称但指令不同的战术会分开，旧报告也能查看。结果只说明已完成比赛的表现，不能排除球员强度和样本量的影响。

比较两套战术时，使用相同对手和种子分别运行，再将不同方案名的 CSV 合并导入做配对分析。目前尚无一键 A/B 队列。场数少或只测一个对手时，结果只能说明这一组比赛的表现。

## 还没接通的部分

- 原始 `.dat` 数据库。若想用初始数据库阵容，可以在游戏新建生涯后立即保存，再导入 `.fm`。
- 存档战术自动读取、完整临场换人和动态改阵。
- 助攻、评分、出场分钟等更多原版统计。
- 战术理解、认同、对手情报和关系对比赛的影响。关系目前只作备注；启用未接通的执行力实验会阻止开赛。
- 跨场伤病、停赛、疲劳、训练和转会。联赛目前每场重置状态；附加赛、公平竞赛分等特殊排名条件也未实现，无法决出时保留并列。

体能、比赛状态、疲劳原值、士气和凝聚力已接入；默认值和可用范围见 [数据说明](docs/DATA_FORMATS.md)。

## 构建与验证

构建需要 Apple Command Line Tools、Swift 5.9+ 和 Python 3.11+。首次构建会安装存档读取依赖；可用 `FM_LAB_PYTHON=/path/to/python3` 指定 Python。打包好的应用自带读取组件，使用时无需 Python。

在仓库根目录运行：

```sh
bash macos/scripts/check.sh
bash macos/scripts/build.sh
python3 macos/scripts/check-engine.py '/你的游戏路径/fm.app'
```

核心检查包含锁定边界、战术分组、旧方案兼容和报告快照；已有 12 种阵型及 FMF 原版回读、真实存档 20 队 380 场验证。新开档也可导入，不再要求已有历史比分。接手开发请看 [开发说明](docs/PORTING.md)；具体测试和 Mac 引擎差异见 [验证记录](docs/MAC_ENGINE_STATUS.md)。

本版基于 [lqf0624/fm-tactics-lab](https://github.com/lqf0624/fm-tactics-lab) 的设计和公开源码，沿用 MIT。数据保存在 `~/Library/Application Support/FM Tactics Lab Mac/`。游戏资源与用户存档不随应用分发。
