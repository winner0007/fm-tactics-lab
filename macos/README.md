# Mac 使用说明 · v0.8.1

这版可以把你设置的球员、战术和定位球交给 FM 原版引擎，跑一批比赛或一个联赛，再看完整结果。

## 启动与第一次测试

退出旧版，打开 `dist/FM Tactics Lab 0.8.1.app`。需要 Apple Silicon、macOS 14+ 和本机 FM27；目前适配 `27.0.0.2493426` 和 `27.0.1.2503222`。临场切换、进球事件和传中统计使用后者。无需安装额外运行库或管理员安装；目前没有苹果开发者账号，应用采用本机临时签名，未做 Developer ID 公证，网络下载副本仍可能被系统拦截。见[打包说明](docs/DISTRIBUTION.md)。

兼容范围按实际引擎文件指纹确认，不是所有旧版本自动兼容：

| 游戏版本 | 已适配范围 |
|---|---|
| `27.0.0.2493426` | 固定战术比赛、游戏战术 FMF 导入导出 |
| `27.0.1.2503222` | 上述功能，以及原版 AI 赛前战术、临场切换、进球事件和传中统计 |

其他 FM27 补丁及 FM26、FM24 没有通用兼容保证。存档读取与比赛引擎适配分别检查，能导入阵容不等于能运行该版本引擎。切换到另一个已适配引擎后需要新建实验；旧报告仍能打开，不跨引擎版本续跑或合并比较。

1. 到「引擎与接入」查找游戏。程序会搜索当前电脑的 Steam 库、应用目录和外置磁盘，也可随时点“指定游戏位置”。
2. 在编辑页顶部选「普通对战」，分别设置主队和对手。战术页与球员页共用当前选中的球队。
3. 排好首发、角色、指令和定位球，填写种子及场数，点击「运行比赛」。场数可设为 1–2000；种子决定本次比赛的随机过程，复测时可使用相同种子。
4. 到「实验对比 → 测试报告」看双方数据和图表。HTML 适合阅读与分享，CSV 适合表格分析，JSON 保留完整数据。

底部“并行”决定同时计算几场，支持 1–256 路，默认给出本机建议并记住修改。通道越多占用资源越多，可以按实际速度调整。停止后点击“继续本批次”，也可从历史批次打开后续跑；更改通道数不会改变比赛种子。每场独立加载引擎，目前尚未复用常驻宿主。

## 选择游戏位置

“指定游戏位置”始终显示，自动找到后也能改选另一处安装。可选择 Steam 游戏库根目录（里面有 `steamapps`）、`steamapps`、`common`、`Football Manager 27` 游戏文件夹，或者直接选择 `fm.app`，不要选择 Steam 客户端 `Steam.app`。完整安装通过检查后会记住位置。

查找使用运行电脑自己的用户目录、Steam 游戏库记录和已挂载磁盘，不依赖开发电脑的用户名或盘符。自动查找不遍历整块磁盘，无法保证覆盖任意嵌套目录；找不到时，通过 Steam 的“浏览本地文件”找到游戏，再在工具里指定 `fm.app`。外置磁盘要先连接，并允许访问所选目录。

“已找到安装”和“版本已适配”是两项检查。换到其他 Apple Silicon Mac 仍需 macOS 14+、完整的 FM27，以及已适配的游戏引擎版本；更新补丁后可能需要重新适配。目前通过了更换用户目录、游戏库路径的隔离测试，尚无其他 Mac 实机验证。

## 战术和球员怎么设置

有球、无球阵型共用 11 名首发，两阶段位置可分别调整。拖到已占用的位置会换位。可套用 12 种阵型，或用 24 个位置自行组合；右侧角色与指令按位置显示，不适用的选项会锁定。

球员可手填、导入 CSV 或从存档读取。比赛带入首发及名单中前 9 名候补。资料按钮可改身高、体重、年龄、CA、声望和性格，隐藏属性在单独页签中编辑。

随机能力可用于全队、某个位置或一个人：随机 1–20、业余 3–7、半职业 5–10、职业 8–13、享誉国内 11–16、洲际 13–18、国际 15–20。中卫更偏防守和争顶，边路球员更偏速度、盘带和传中；隐藏属性与性格单独随机。档次只是本工具的属性范围，CA 另设。再次随机会替换原属性，可用 ⌘Z 撤销。

定位球包含攻守角球、三类任意球和界外球，共 10 种情形，每种可设 1–3 套套路。任务、使用频率、备用安排、主罚人和队长都可调整。

上方三个战术按钮分别编辑三套方案，阵型、角色、心态和指令各自保留；首发、候补、定位球和开赛状态共用。到“临场策略”开启自动切换，选择开场方案，设置时间范围和比分条件。规则从上到下匹配，先符合的生效；切换间隔用于避免频繁来回改阵。未开启时使用当前编辑的方案。双方及各支联赛球队都可单独设置。

初始三套方案复制当前战术，进攻／防守方案只预设不同心态，需自己调整。切换仅在“指定战术”模式执行，由测试器规则触发、原版临场指令应用。“原版 AI 制定”使用另行生成的赛前方案。完整规则及边界见[战术与 AI 说明](docs/TACTICS_AND_AI.md)。

## 保存阵容与交换游戏战术

在「阵容方案库」填写名称，保存当前球队。球员、候补、属性、性格、双阶段战术、定位球和开赛状态一起保留。重开应用仍可载入，也可复制为新联赛球队，或导出／导入方案 JSON。载入替换当前编辑球队，可撤销；归档文件仍保留，可重新导入。

工作台的「战术文件」可导入和导出 FM27 游戏战术 `.fmf`。导出调用本机原版序列化器，封装后再通过原版读取器逐项核验；不一致则不写出目标文件。保存到游戏的 `tactics` 文件夹后，在游戏战术页面选择载入。导入只替换阵型、角色、职责、心态与指令，保留当前球员、定位球和状态。指定球员盯人按当前对手名单解析，需要核对目标。

与 Windows 原项目一样，战术 FMF 不包含球员属性和定位球套路；完整实验配置请保存到方案库。定位球 FMF 的单独交换尚未适配。

2026-11-13，用户已确认游戏内战术导入和导出实测可用；本次构建另通过 12 种阵型的原版 FMF 写入与回读检查。导出始终取当前工作台可见方案，不因实验选择了随机或 AI 而临时换成另一套战术。

FMF 导入／导出针对当前正在编辑的那套战术。三套方案和切换规则随完整球队 JSON 保存，不会写进单个游戏战术 FMF。

## 自己的球队和联赛是什么关系

**每支联赛球队都有自己的球员、战术和定位球。** 顶部的「普通对战／联赛球队」和球队名称告诉你正在编辑谁。

- 把普通对战球队带进联赛：点击「复制普通对战主队」或「复制普通对战对手」。复制之后两份数据各自保存。
- 修改联赛球队：在该队所在行打开「阵容与属性」或「战术与定位球」。两个入口编辑同一支队，修改自动保存。
- 调整随机球队：可以逐人修改，也可以点「随机本队能力」重新抽取。只影响这一队的属性与性格，名单和战术保留。个人随机在球员页操作。

球队名称在联赛列表改，战术名称在工作台改。返回普通对战后，原来的主队和对手仍在。

「教练与锁定」可以手动指定教练，或选择当前方案中的已有教练。教练与战术分别锁定：锁定战术会阻止改阵、改指令和载入其他战术，仍可调整首发、主罚人、球员属性和开赛状态。当前没有董事会换帅流程，教练姓名本身不参与比赛计算；未锁定也不代表 AI 会自动临场调阵。

## 导入球队并运行联赛

在「实验对比」的“双方战术配置”中，可逐队选择指定、随机或原版 AI，也可统一设置。指定战术使用工作台的三个方案和临场规则；随机战术抽取阵型、心态及部分指令，保存种子后整批固定，重新抽取不改球员；原版 AI 根据本次双方名单和教练参数制定赛前方案，生成失败会停止，不会偷偷换成模板。

联赛的“统一战术”用于没有单独设置的对手。新联赛默认对手使用原版 AI，“我的测试球队”使用工作台方案；各队都能单独覆盖。统一选择“指定战术”是各用各的工作台方案；“统一采用普通主队战术”才会把同一套战术复制给所有未锁定球队，保留各自球员和开赛状态。锁定战术的球队始终使用指定方案。旧版联赛保留原来的固定战术，不自动改为 AI。

“我的测试球队”在积分榜、球队场均、球员榜、逐场比赛和 HTML 报告中用星标与绿色标出，球员榜可只看本队。切换去编辑对手不会改变标记；报告中也可以另选标记球队，不改变比赛输入。

「联赛实验」支持自定义、随机、`.fm` 存档及原始 DAT 球队，可以混用。也可以用“初始化 JSON”保存和复用一整套联赛设置。

顶部「导入真实球队」可在战术、球员和联赛页打开。先选数据起点，再选球队或完整联赛；单队导入会显示替换目标。整联赛导入前可选择排名规则，导入后继续核对。

导入存档时，先选文件，再搜索单队或选择完整联赛。整联赛导入会保留对阵和日期，从头重赛，不带入旧比分。导入的是一线队球员；战术仍需自己核对。替换现有联赛前会自动备份原配置。

使用初始数据库时，点“读取游戏数据库”，程序会定位已找到的 FM 安装目录；找不到时可在“更多”选择完整的 `2700_fm` 文件夹或其中一个 DAT 文件。当前支持 DAT schema 4000 / 数据库 2700，可搜索球队和联赛，导入单队或整联赛。读取俱乐部归属、球员名单、能力、隐藏属性、性格和可确认的主教练资料；初始球员池没有存档的一线队注册，按能力保留最多 100 人，比赛仍只带工作台首发与候补。

DAT 中未设定和负值预设属性会按位置、能力及固定球员 ID 种子补全，性格独立取值；原始值和补全数量保存在导入目录。它们不是 FM 开档后的数值，年龄按 2026-07-01 计算。未加载 DBC/LNC 编辑补丁、开档初始化器及完整联赛规则；联赛归属来自 DAT，循环赛程由工具生成，排名规则需要核对。想复现某次生涯的球员状态，请导入该生涯存档。

加入 2–40 队后，选择单／双循环、积分和同分排序，或使用英超／西班牙排名预设。可跑 1–100 次赛季，总计最多 20,000 场。点击「运行联赛」后看积分榜、球队场均表现、球员榜和逐场成绩；停止后可以继续。

每次开始实验都会保存当时的球队、规则和种子。**之后改阵容只影响新实验；继续上次实验仍用原配置。** 比赛逐场保存，意外退出后可恢复已完成记录。报告页可打开保存目录，详细格式见 [数据文件与实验记录](docs/DATA_FORMATS.md)。

## 报告能看到什么

普通测试有胜平负、胜率区间、双方阵容和指令；“战术效果”包含战术统计、进攻与机会、进球分布、进球时间与方式、临场切换、逐场复盘。可按战术查看场均控球、传球、传中、射门、射正、进球和 xG，比较双方成功率、进球率及进失球时段。联赛选择分析球队后，主客场统一为本队视角。

球员统计包括进球、助攻、xG、射门、射正、传球、成功传球、传中、成功传中和红黄牌，球队另有控球率。进球事件以终场确认为准，取消的进球不计入；非点球、点球和乌龙已区分，头球、角球等细分方式仍待核实。旧报告没有记录的事件不会按零补全。

整场报告按场均计算；临场方案按实际生效时间分段，次数换算为每 90 分钟。射门转化率不含对方乌龙球，“有进球场次占比”则按比赛比分计算。不同比分下启用的方案不能仅凭分段统计认定优劣，计算口径见[报告说明](docs/TACTICS_AND_AI.md#报告怎么看)。

联赛的「面对不同战术的表现」先选分析球队，再按完整战术或双阶段阵型分组，可筛选主客场、合并重复赛季。表格保留场次、胜平负、场均进失球和 xG，以及双方首发平均 CA、对手 CA 范围。相同名称但指令不同的战术会分开，旧报告也能查看。结果只说明已完成比赛的表现，不能排除球员强度和样本量的影响。

比较两套战术时，使用相同对手和种子分别运行，再将不同方案名的 CSV 合并导入做配对分析。目前尚无一键 A/B 队列。场数少或只测一个对手时，结果只能说明这一组比赛的表现。

## 还没接通的部分

- DAT 编辑补丁与 FM 开档初始化器、数据库完整联赛规则自动解析。当前已支持 2700 原始球员池与联赛归属。
- 存档当天实战战术还原、自定义临场换人策略和生涯 AI 临场执教。
- 评分、出场分钟、头球与定位球进球等更多原版统计。
- 战术理解、认同、对手情报和关系对比赛的影响。关系目前只作备注；启用未接通的执行力实验会阻止开赛。
- 跨场伤病、停赛、疲劳，以及训练、成长、衰减、退役和转会。联赛目前每场重置状态，日期不会推进球员生涯；附加赛、公平竞赛分等特殊排名条件也未实现，无法决出时保留并列。

体能、比赛状态、疲劳原值、士气和凝聚力已接入；默认值和可用范围见 [数据说明](docs/DATA_FORMATS.md)。

## 构建与验证

构建需要 Apple Command Line Tools、Swift 5.9+ 和 Python 3.11+。首次构建会安装存档读取依赖；可用 `FM_LAB_PYTHON=/path/to/python3` 指定 Python。打包好的应用自带读取组件，使用时无需 Python。

在仓库根目录运行：

```sh
bash macos/scripts/check.sh
bash macos/scripts/build.sh
python3 macos/scripts/check-engine.py '/你的游戏路径/fm.app'
```

核心检查包含锁定边界、战术分组、旧方案兼容和报告快照；已有 12 种阵型及 FMF 原版回读、真实存档 20 队 380 场验证。新开档也可导入，不再要求已有历史比分。接手开发请看 [开发说明](docs/PORTING.md)；具体测试和 Mac 引擎差异见 [验证记录](docs/MAC_ENGINE_STATUS.md)。

本版基于 [lqf0624/fm-tactics-lab](https://github.com/lqf0624/fm-tactics-lab) 的设计和公开源码，沿用 MIT。数据保存在 `~/Library/Application Support/FM Tactics Lab Mac/`。游戏资源与用户存档不随应用分发。
