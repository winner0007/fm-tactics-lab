## 使用入口

打开 `dist/FM Tactics Lab 0.4.app`，在「引擎与接入」自动找到游戏后设置起始种子和场数，点击「开始原版模拟」。支持 1 / 5 / 10 / 20 场，逐场独立进程；可以停止，已完成场次保留。引擎页显示最近一场累计 xG，实验页显示本批次球队图表和球员基础统计。

球员姓名尚未映射，界面以原版 ID 标识。未确认的评分、助攻、出场分钟、跑动距离等保持缺失。每场日志、进度采样与完整报告存入应用数据目录；游戏包和存档不作修改。Mac 应用不携带游戏二进制、FMF 资源或 PKM 输入。

本机版本 `27.0.0.2493426`，插件包含 arm64 / x86_64；本次宿主仅支持 arm64。每次运行重新校验原始插件 SHA-256：

`774cacde63567fd3901c47719e7a6ed94cc3a0a62e9b94989dcac6b4890ec0e1`

输入为安装包的 `Contents/PlugIns/game_plugin.bundle/Contents/Resources/data/game_simulation/test match/match.pkm`（60,314 字节），SHA-256：

`39c594c7e876cc0ad325dfa51c377f4cf360840612479ed72d800ec548e504b6`

二进制或输入不匹配直接拒绝，不能仅凭版本字符串调用旧地址。Intel Mac、其他补丁版本、自选 PKM、游戏存档尚未接入。

## 实际解决的 Mac 差异

- Mach-O 动态插件及其 `@loader_path/../Frameworks` 依赖，通过独立进程加载完整原文件。
- ICU 和模拟资源位于 **game_plugin.bundle 内部 Resources**。初始化原生文件系统和资源管理器，挂载 `simatch.fmf`、`simatchshared.fmf` 的虚拟目录后才能找到 xG 模型；只找到文件不够。
- arm64 C++ 间接返回结果使用 `x8`，需要 ABI 桥接；不能按 Windows 返回值约定调用文件／归档工厂。
- macOS TLV 描述符获取比赛线程上下文；不能复用 Windows TLS 槽。
- 对象大小、字段偏移和虚表布局不同。Mac match 大小为 `0x15590`；准备阶段种子位于 `+0x18`，不是 Windows 的 `+0x20`。比分访问使用 Mac 自身的结果对象虚表。
- 按原游戏性能测试路径构建派生比赛对象，调用原版反序列化、准备和运行方法。不修改机器指令，不伪造准备标志，不调用强制比分结束。
