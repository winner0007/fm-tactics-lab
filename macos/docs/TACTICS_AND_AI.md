# 战术规则、教练与实验范围

这个工具用 FM 原版比赛引擎比较战术。球员、球队和规则在开赛时保存成快照，每场从相同条件开始；联赛把这些比赛排成赛程、累计成绩，不推进完整职业生涯。

## 三套战术怎样切换

每支球队可保存三套战术，分别编辑有球／无球阵型、角色、心态和指令。首发、候补、定位球和开赛状态共用。新建时三套都复制当前战术，第二、第三套只预设更进攻／更防守的心态；“加强进攻”等名称不是原版 AI 生成的成品战术，仍需自己调整。

开启“临场策略”后，选一套作为开场方案，再添加规则。例如：60 分钟后落后，改用第二套；领先至少 3 球，改用第三套。

- 最多 12 条规则，按列表从上往下匹配，第一条符合的生效。
- 时间范围包含起止分钟；使用比赛显示时钟，比分条件始终从这支球队的视角判断。
- 可选任意比分、落后、平局、领先、领先至少 N 球、落后至少 N 球。
- 两次切换的最小间隔可设 1–30 分钟，按实际经过时间计算，包含补时。冷却期间保留当前方案；规则目标就是当前方案时不重复执行。
- 没有规则符合时，可选择回到开场方案，或保留当前方案。未开启自动切换时，使用正在编辑的方案。

条件由测试器判断，变更通过 **FM 原版临场指令**应用到正在进行的比赛，不会重开比赛。应用后核对双阶段位置、角色、个人／球队指令，以及比分时钟、球员身份和体能是否保留。每次切换的时间、比分、原因和统计快照都会写入报告。主队、对手和联赛每支球队分别执行自己的规则。

这项适配目前只用于 `27.0.1.2503222`。没有加入自定义换人策略，也没有按疲劳、红牌或伤病触发规则。

## 主教练与原版 AI 的关系

实验双方与联赛各队可以选择“指定战术”“随机战术”或“原版 AI 制定”，支持统一设置和逐队覆盖。新联赛默认对手使用 AI，我的测试球队使用工作台方案；旧联赛保留原先设置。

原版 AI 模式先把双方 11–20 人名单和教练参数写入独立的原版引擎进程，运行赛前准备，在比赛尚未开始（0 tick）时读取首发顺序、双阶段站位、角色和指令。检查球员身份、属性和教练参数后，将结果保存为固定输入，再启动正式比赛进程。生成过程不运行近似模型；失败会停止该实验。

普通批次只生成一次；联赛每个主／客对阵分别生成一次，重复赛季和续跑复用已保存结果。生成进程可以重选传入名单内的首发，不会从完整数据库临时召入其他球员。定位球和开赛状态沿用该队设置。AI 模式不同时执行工作台三个方案的手动切换规则；要测试自己的临场规则，选择“指定战术”。

`.fm` 导入读取可确认的一线队主教练，DAT 读取能唯一确认的主教练。实际送入 AI 的是 52 项教练参数及 8 个阵型偏好码，其他未映射的教练资料仍来自原版测试载体。DAT 未设定教练值保留 0，不冒充游戏开档后的补全参数。遇到无人、多个候选或无法读取时，界面和生成记录会明确标注使用原版测试教练参数。可从已导入的其他球队选择教练；手动填写姓名和风格标签不会自动获得同名教练的真实能力。

“锁定教练”防止在编辑器里更换指定教练；“锁定战术”保护战术内容、三套方案和切换规则。它们不等于接入了游戏的聘任、董事会或解雇逻辑。工具没有跨场换帅流程，因此未锁定的教练也不会因为成绩差而下课。

工作台导入后仍显示可编辑的初始模板；选 AI 时实际执行的是实验生成并保存的方案，报告记录实际来源和阵型。它不是存档某一天的实战战术还原，也不包含原版生涯的 AI 临场执教、自动聘任和解雇。自定义比分切换规则仍是测试器规则。

## 球员状态会不会跨场变化

| 项目 | 当前处理 |
| --- | --- |
| 属性、年龄、身高、体重、CA、声望、性格 | 使用开赛快照；不随赛程自动更新 |
| 体能、比赛状态、疲劳原值、士气、凝聚力 | 每场按设置重新写入并回读；单场内的原版运算仍由引擎执行 |
| 成长、衰减、训练、退役、转会 | 不运行相关生涯流程 |
| 伤病、停赛、疲劳累积 | 不延续到下一场；不能把它理解为关闭了原版单场中的所有事件 |
| 战术理解、认同、对手情报 | 尚未接通；启用不支持的执行力实验会阻止开赛 |
| 球员关系 | 只作备注，没有转成属性或比赛加成 |

重复赛季只是增加独立比赛样本，日期是赛程信息，不会让球员变老。若要测试体能下降后的战术，需要另建一组开赛状态做对照。

## 联赛与赛程

完整存档赛程可导入后从头重赛；没有赛程时，工具按选定的单／双循环规则排出对阵。这个排程不是调用 FM 职业生涯的赛程生成器。积分、同分排序可配置，尚未实现分组、附加赛、公平竞赛分与行政扣分。无法判定的同分保留并列。

联赛球队各自保存阵容和策略。运行后改编辑器只影响新实验，继续旧实验仍使用原快照、引擎版本和种子。随机单队不会改变其他球队。

## 报告怎么看

“战术统计”按实际执行配置分组，包含三套方案和切换规则；名称相同但配置不同也会分开。联赛还可按对手战术或阵型筛选，同时列出主客场、样本数和首发平均 CA。

- **场均值**：总量除以有该项数据的完赛场次。控球率逐场等权平均。
- **传球／传中成功率**：成功总次数除以尝试总次数，不平均每场百分比。
- **射门转化率**：本队球员进球总数除以射门总数，排除对方乌龙球。
- **有进球场次占比**：至少进一球的场次除以完赛场次，比分包含受益乌龙球。
- **临场分段**：以切换时的统计快照划分。进失球和 xG 显示累计值；传球、传中、射门换算为每 90 分钟；控球率按这段时间双方控球时长计算。只使用有快照的时间，不把旧报告缺失项补零。
- **进球事件**：以原版终场结果与事件表交叉确认，排除被取消的进球；区分非点球、点球和乌龙球。头球、角球、任意球等更细分类尚未单独验证。

分母为零或数据缺失时显示“—”。补时分别并入上、下半场最后一个进球时段。落后时启用的战术与领先时启用的战术，面对的比赛背景不同，不能仅凭分段数据判断谁更强。

完整球队 JSON 保存三套方案和规则。游戏战术 FMF 只导入／导出当前编辑的一套，不包含球员属性、定位球套路或临场规则。
