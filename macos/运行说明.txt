FM 战术实验室 Mac 0.8.0

开始使用
1. 退出旧版，完整解压 ZIP，把 FM Tactics Lab 0.8.0.app 放到自己的“应用程序”文件夹或其他本地目录，双击打开。
2. 需要 Apple Silicon、macOS 14+ 和本机完整安装的 FM27。
3. 到“引擎与接入”自动查找游戏。原版 AI 制定战术与临场切换需要 27.0.1.2503222。
4. “导入真实球队”可选 .fm 存档或“读取游戏数据库”。DAT 未设定的属性由工具补全，导入页会说明；不是游戏开档后的数值。
5. “实验对比”设置双方指定／随机／原版 AI 战术；“联赛实验”可以统一设置，也能逐队覆盖。指定战术使用工作台方案，AI 生成本次对阵的赛前方案。
6. 联赛中选好“我的测试球队”，积分榜、球队和球员数据会标记这支队。它默认使用工作台战术，对手默认原版 AI。

应用自带数据读取组件，不需要 Python、Homebrew、管理员安装或完全磁盘访问权限。没有 Apple 开发者账号，因此只有本机临时签名，没有苹果公证；网络下载仍可能出现首次打开提示。

通过百度网盘等渠道分发
直接上传完整的 FM-Tactics-Lab-Mac-0.8.0-arm64.zip。不要上传拆开的 .app，不要在线解压后重新打包，也不要在 .app 内添加网盘说明、广告或其他文件。说明文件放在应用之外。
下载完整 ZIP 后在 Mac 本地解压。包内正常只有一个版本文件夹，里面是应用与本说明；应用内部有运行组件和许可文件。

如何检查下载文件是否变化
在终端输入“shasum -a 256 ”（最后保留空格），把下载的 ZIP 拖进终端，再按回车。对照 GitHub 上该版本 SHA256 文件中的完整 64 位结果：
https://github.com/winner0007/fm-tactics-lab/blob/macos-v0.8.0/macos/releases/macos-v0.8.0-SHA256.txt
必须从上述独立发布页取校验值，不能只信同一个网盘里的校验文本。结果一致，表示 ZIP 内容没有改变；不代表苹果已公证。不同则不要打开，删除下载副本并重新下载，仍不一致时联系发布者。

提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”
先核对来源与 ZIP 校验值。确认无误后尝试打开应用，再到“系统设置 → 隐私与安全性”，找到该应用的拦截记录，点“仍要打开”，按系统提示确认。只放行这一款已核验的应用，不需要关闭 Gatekeeper 或 SIP。系统可能要求用户确认身份；本说明不能保证每个系统都免提示。

提示“已损坏”或解压失败
1. 先验证 ZIP；不一致就重新下载。不要使用第三方提供的“修复安全设置”脚本。
2. ZIP 一致时，用 Mac 自带的归档实用工具完整解压，确认没有在应用内部添加文件，也没有覆盖到旧版 .app 上。
3. 仍打不开，可在终端输入“codesign --verify --deep --strict ”，将解压出的 .app 拖进去并按回车。没有错误且命令成功退出表示签名完整性检查通过；这不是公证认证。
4. 如果签名检查报错，停止使用该副本，重新解压或联系发布者并提供原始提示。如果校验和签名都通过，再检查“隐私与安全性”是否提供“仍要打开”；没有该选项时提供原始提示及 macOS 版本给发布者，不要批量移除隔离标记。
如果系统明确报告恶意软件或“将损坏电脑”，不要按普通开发者提示处理，也不要绕过拦截。

苹果官方操作说明：https://support.apple.com/zh-cn/102445
“风险”提示可能来自下载隔离标记或未公证签名，仅凭提示不能认定网盘注入了文件。ZIP 打包和校验能发现传输变化，不能代替 Developer ID 与苹果公证。

实验范围
每场重置状态，不推进成长、衰减、训练、退役、转会或跨场伤停。原版 AI 只生成赛前方案，同一批次／同一联赛主客对阵固定使用这份结果；不模拟生涯换帅和 AI 临场执教。缺少或无法唯一确认主教练时，使用原版测试教练参数并标明来源。DAT 不包含开档初始化、编辑补丁和完整联赛规则，导入后请核对排名设置。

数据保存在 ~/Library/Application Support/FM Tactics Lab Mac/。清理旧应用不会删除方案与历史结果；游戏更新后新建实验，避免混用引擎版本。
