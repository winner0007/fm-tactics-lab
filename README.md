# FM 战术实验室 · Mac 版

**简体中文** | [English](README.en.md)

在 Mac 上用本机 FM27 原版引擎测试战术：设置双方阵容，反复比赛，看球队和球员表现；也可以导入存档中的球队，跑完一个联赛，查看成绩与排名。

这是 [lqf0624/fm-tactics-lab](https://github.com/lqf0624/fm-tactics-lab) 的 fork。原项目提供 Windows 版战术编辑、存档对战和批量测试；我们在此基础上增加了 Mac 原生界面和引擎适配。当前版本 **0.5**，基于上游 **v1109.3 / `6cb32bf`**，沿用 [MIT 许可](LICENSE)。

## 现在可以做什么

- **复用方案**：游戏战术 FMF 导入／导出，经 Mac 原版序列化与回读核验；完整球队可命名存入阵容方案库。
- **编排战术**：双阶段战术板、拖动换位，12 种阵型、24 个位置、79 个角色项；球队指令、球员指令和定位球按原项目的操作方式设置。
- **配置球员**：手动填写、导入 CSV 或 `.fm` 存档；七档随机能力支持全队、位置和个人。随机结果考虑位置特点，隐藏属性和性格单独生成。
- **批量比赛**：自定义 1–2000 场，工作台设置会传入原版引擎。赛后查看双方统计、阵容、图表和完整报告。
- **联赛实验**：2–40 支自定义、随机或存档球队互相比赛，可选循环和排名规则，查看积分榜、球员榜和多次赛季的排名变化。

普通对战和联赛各自保存球队。把自己的球队加入联赛时会复制一份；以后从联赛列表打开该队的阵容或战术，修改就直接保存到这支联赛球队。每次实验另存开赛配置，旧结果不会随着编辑改变。

## 开始使用

需要 Apple Silicon Mac、macOS 14+，以及本机完整安装的 FM27。目前适配游戏版本 **27.0.0.2493426**；游戏更新后可能需要重新适配。

打开应用后，先到「引擎与接入」查找游戏，再到「战术工作台」设置双方，填入场数并点击「运行比赛」。真实球队从顶部「从 FM 存档导入」选择，整赛季测试从「联赛实验」进入。详见 [Mac 使用说明](macos/README.md)。

从源码构建需要 Apple Command Line Tools 和 Python 3.11+；使用打包好的应用不需要 Python。

```sh
git clone https://github.com/winner0007/fm-tactics-lab.git
cd fm-tactics-lab
bash macos/scripts/check.sh
bash macos/scripts/build.sh
open 'macos/dist/FM Tactics Lab 0.5.app'
```

## 还没接通的部分

原始 `.dat` 数据库、存档战术自动读取、定位球 FMF 交换和临场指挥尚未完成。初始阵容可通过游戏开档后立即保存的 `.fm` 导入。联赛每场重置开赛状态，不延续伤病、停赛、疲劳或转会；排名规则也暂不包含附加赛等特殊情况。助攻、评分等尚未核实的统计留空。

已用真实存档的 **20 支球队跑完 380 场**，并验证批量比赛、停止续跑、数据恢复和存档导入。[验证记录](macos/docs/MAC_ENGINE_STATUS.md)列出了具体范围。
