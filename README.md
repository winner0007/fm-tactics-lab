# FM 战术实验室 · Mac 版

**简体中文** | [English](README.en.md)

在 Mac 上用本机 FM27 原版引擎测试战术：设置双方阵容，反复比赛，看球队和球员表现；也可以导入存档中的球队，跑完一个联赛，查看成绩与排名。

这是 [lqf0624/fm-tactics-lab](https://github.com/lqf0624/fm-tactics-lab) 的 fork。原项目提供 Windows 版战术编辑、存档对战和批量测试；我们在此基础上增加了 Mac 原生界面和引擎适配。当前版本 **0.8.2**，基于上游 **v1109.3 / `6cb32bf`**，沿用 [MIT 许可](LICENSE)。

## 现在可以做什么

- **复用方案**：游戏战术 FMF 导入／导出，经 Mac 原版序列化与回读核验；完整球队可命名存入阵容方案库。
- **编排战术**：双阶段战术板、拖动换位，12 种阵型、24 个位置、79 个角色项；球队指令、球员指令和定位球按原项目的操作方式设置。
- **配置球员**：手动填写、导入 CSV、`.fm` 存档或原始 DAT 数据库；七档随机能力支持全队、位置和个人。随机结果考虑位置特点，隐藏属性和性格单独生成。
- **临场策略**：每队准备三套战术，按时间、领先或落后等条件自动切换，记录切换时的比分和各方案实际表现。
- **并行比赛**：自定义 1–2000 场、1–256 路并行，记住上次设置，默认按本机配置给建议。停止后只补跑缺失场次，普通对战和联赛都可续跑。
- **赛后复盘**：按战术比较场均控球、传球、传中、射门、进球与成功率；查看比分分布、进球时段、点球与乌龙球、助攻和逐场 xG 走势，可导出带图表的报告。
- **联赛实验**：2–40 支自定义、随机或存档球队互相比赛，可选循环和排名规则，查看积分榜、球员榜和多次赛季的排名变化。
- **战术来源**：实验双方和联赛各队都可选指定、随机或原版 AI；支持统一设置与逐队覆盖。新联赛默认对手 AI、我的球队用工作台方案。
- **固定对照**：球队可分别锁定教练与战术；联赛报告按对手完整战术或双阶段阵型统计表现，列出场次、主客场、进失球、xG 和首发强度。
- **历史与存储**：查看和清理测试记录，自选测试数据目录并迁移历史；战术、阵容方案和联赛设置独立保留。

普通对战和联赛各自保存球队。把自己的球队加入联赛时会复制一份；以后从联赛列表打开该队的阵容或战术，修改就直接保存到这支联赛球队。每次实验另存开赛配置，旧结果不会随着编辑改变。

## 开始使用

需要 Apple Silicon Mac、macOS 14+，以及本机完整安装的 FM27。目前适配游戏版本 **27.0.0.2493426、27.0.1.2503222**；游戏更新后可能需要重新适配。

原版 AI 赛前战术、临场切换和进球事件已接入 **27.0.1.2503222**；旧版仍支持固定战术比赛与 FMF 读写。更新游戏后请新建实验；旧报告可以查看，不与新版引擎混合续跑。

打开应用后，先到「引擎与接入」查找游戏，再到「战术工作台」设置双方，填入场数并点击「运行比赛」。真实球队从顶部「导入真实球队」选择，整赛季测试从「联赛实验」进入。详见 [Mac 使用说明](macos/README.md)。

游戏目录按运行电脑的用户目录和 Steam 库记录查找，也可随时点“指定游戏位置”，选择 Steam 游戏库、游戏文件夹或 `fm.app`。不绑定开发电脑路径；自动查找不能保证覆盖所有位置，游戏补丁也需单独适配，不是所有旧版本自动兼容。

从源码构建需要 Apple Command Line Tools 和 Python 3.11+；使用打包好的应用不需要 Python。

当前包采用本机临时签名，没有苹果开发者账号和公证。本机构建版可直接打开；通过网络分发时不能保证绕过系统的首次打开检查。应用不需要管理员安装或完全磁盘访问权限，具体见[打包与签名说明](macos/docs/DISTRIBUTION.md)。

```sh
git clone https://github.com/winner0007/fm-tactics-lab.git
cd fm-tactics-lab
bash macos/scripts/check.sh
bash macos/scripts/build.sh
open 'macos/dist/FM Tactics Lab 0.8.2.app'
```

## 还没接通的部分

原始 DAT 已接入 2700 数据库，可选真实球队和联赛；未设定属性按工具规则补全，排名规则仍需选择，未加载编辑补丁或 FM 开档初始化器。存档中的当天实战战术、定位球 FMF 交换和自定义换人策略仍未接通。联赛每场重置开赛状态，不累积伤病、停赛和疲劳，不推进成长、衰减、训练、退役或转会；排名规则也暂不包含附加赛。评分、出场分钟、头球和角球进球等未核实的统计不补算。

临场规则由测试器判断，再调用原版指令切换战术。AI 模式调用原版赛前准备生成战术，固定保存后再运行比赛；有可确认的教练资料就使用其参数，否则明确使用原版测试教练。不会推进生涯聘任、解雇和 AI 临场执教。详见[战术规则、教练与实验范围](macos/docs/TACTICS_AND_AI.md)。

新版引擎已用真实存档的 **24 支球队跑完 552 场**，并验证批量比赛、停止续跑、数据恢复和存档导入。[验证记录](macos/docs/MAC_ENGINE_STATUS.md)列出了具体范围。

已核对上游 [v1112](https://github.com/lqf0624/fm-tactics-lab/releases/tag/v1112)。Mac 已支持多进程并行；原版 AI 赛前生成已接入；通道内持续复用引擎和带权重的随机战术池仍待移植。具体差距见[开发说明](macos/docs/PORTING.md)。
