# FM 战术实验室 · Mac 原生扩展

**简体中文** | [English](README.en.md)

本仓库是 [lqf0624/fm-tactics-lab](https://github.com/lqf0624/fm-tactics-lab) 的 fork，在保留上游 Windows 实现的基础上，新增 `macos/` 下的 SwiftUI 客户端与 Mac 原版比赛宿主。当前 Mac 版本为 **0.4**，上游基线为 **v1109.3 / [6cb32bf](https://github.com/lqf0624/fm-tactics-lab/commit/6cb32bfab936d1ce2a0558a70f489537edfb5442)**。

## 原项目是什么

FM Tactics Lab 是一款使用本机 FM27 原版详细比赛引擎的战术实验工具。上游 Windows 版提供双阶段战术板、球员与阵容配置、定位球、存档对战、FMF 战术读写，以及按种子批量运行、A/B 战术对比和比赛统计。原项目将配置、比赛宿主和结果分析连接起来，方便在固定条件下重复测试战术。

上游采用 Web 编辑器、Python 本地服务、C# 桌面启动器和 Windows C++ 比赛宿主。Mac 的 Mach-O、arm64 ABI、资源目录和线程上下文不同，因此本 fork 新增独立的 Mac 实现。**原项目的设计与 Windows 实现归功于上游作者和贡献者**；工具代码继续使用 [MIT 许可证](LICENSE)。

## Mac 构建与使用

需要 macOS 14+、Apple Silicon 和 Apple Command Line Tools；原版模拟还需要用户本机完整安装的、适配版本的 FM27。

```sh
git clone https://github.com/winner0007/fm-tactics-lab.git
cd fm-tactics-lab
bash macos/scripts/check.sh
bash macos/scripts/build.sh
open 'macos/dist/FM Tactics Lab 0.4.app'
```

在「引擎与接入」设置起始种子与场数，点击「开始原版模拟」。当前适配 `27.0.0.2493426` 的指定 arm64 二进制，每次运行校验 SHA-256，其他构建会拒绝运行。构建产物位于本地 `macos/dist/`，不存入 Git；GitHub 源码不包含游戏引擎、资源包、PKM、存档或本机运行日志。

- [Mac 完整使用与构建说明](macos/README.md)
- [Mac 0.4 更新记录](macos/CHANGELOG.md)
- [原版引擎验证、统计范围与适配依据](macos/docs/MAC_ENGINE_STATUS.md)
- [后续接入路线](macos/docs/PORTING.md)

当前验证：34 项核心检查通过；9 场原版引擎回归通过，包括同种子复跑、不同种子、边界种子；11 类无效／不完整结果检查通过；应用内 5 场连续比赛生成 200 条球员记录，持久化恢复一致。证据生成方式见 Mac 文档，原始本机证据不上传。上述验证不代表与职业生涯手动比赛条件完全等价。

后续重点是自定义阵容、战术与定位球的原生写入和回读，然后接入姓名、更多球员指标、存档与 FMF。

## 上游 Windows 使用说明

以下保留基于上游 v1109.3 的 Windows 使用说明。EXE 下载、职业生涯存档对战与 FMF 支持属于上游 Windows 版；Mac 当前功能以本页上方及 `macos/README.md` 为准。

在自由推演中设置双方球员，或导入 FM27 职业生涯存档与同联赛球队对战。用比分、xG、射门和控球等数据比较战术表现。

它适合解决这些问题：

- 同一批球员，哪套阵型更合适？

- 一套战术面对不同对手，表现是否稳定？

## 推演原理

工具直接加载本地 FM27 的原版比赛引擎，提交双方的球员、阵型、角色、指令和定位球设置，由原版代码计算球员决策、跑位、传球、对抗、射门和比赛规则，推进到自然终场。

```text
球员与战术 → 原版引擎计算完整比赛 → 比分、事件和统计 → 多场汇总与战术对比
```

**比赛计算和画面展示是两个层面。** 比赛引擎推进球员、球和事件，画面呈现这些比赛状态。本工具把详细比赛放在后台运行，省去球场画面的展示，直接收集比赛结果。

### 和手打、度假、跳过比赛有什么关系？

本工具运行的是**原版详细比赛计算**，对应进场手打时所使用的详细模拟这一层。你在开赛前设好战术，让引擎在后台把整场踢完，再查看结果；比赛中由玩家临时改阵、喊话等操作留在正常游戏中进行。

“后台运行”和“跳过画面”也可以使用完整比赛逻辑。度假、即时结果等入口还涉及比赛任务和助教接管等外围流程。这里最直接的理解是：**把原版详细比赛引擎变成可以批量运行的战术试验工具。**

### 结果为什么能用于测试战术？

球员动作和比赛规则使用原版实现，比分、xG、射门、传球等数据也从原版比赛对象中读取。工具把配置、运行和汇总集中到一起，方便你在固定条件下反复测试。

相同输入和种子可用于复查实验；战术对比会让两套方案使用同一组种子分别运行。多场结果帮助你观察调整带来的平均变化，减少单场偶然性的影响。

## 下载与启动

当前源码版本为 **v1109.3**。桌面版下载见 [GitHub Releases](https://github.com/lqf0624/fm-tactics-lab/releases)，从托盘退出旧版后再启动新版。


准备好可正常运行的 FM27，打开 Steam 并登录拥有游戏的账号，再启动桌面 EXE。工具会查找本地游戏；也可以在顶部引擎设置中，手动选择包含 `fm_Data` 和 `shared` 的游戏根目录。

EXE 自带 Python 运行环境，玩家无需安装 Python 或编译工具。双击运行后，按下面的步骤开始测试。源码构建步骤见[开发者文档](docs/DEVELOPMENT.md)。

## 存档对战

1. 切换到「存档对战」，导入 FM27 的 .fm 存档，再选择自己执教的球队。
2. 载入存档战术，检查一线队球员属性，按需要调整首发与替补。
3. 从同联赛选择对手，可先查看对手的有球和无球战术板，再运行主客场推演。

对手战术按存档中主帅的风格与阵型偏好匹配原装预设。只有主帅和战术偏好均可核实的球队才可选。对手名单按需批量读取，开赛准备可查看进度或取消。

## 存档战术

在「存档战术」页面选择并读取存档，然后按当前联赛列出除你以外的球队教练偏好预设。可以把全部战术导出到本机文件夹，也可以一键加入客队战术池。存档不保存国家与联赛名称，页面按当前联赛分组；导出的对手文件是预设近似，不是当天实战战术。

## 自由推演

### 1. 准备球队

从内置的双方球员输入开始，设置主队、客队和首发名单。双方都可以单独编辑。

在“球员属性”中，可以查看和调整实验用的球员能力、位置熟练度等输入。所有调整都保存在工具方案中，可以导出 JSON 留作下一次实验。

![球员属性与全队批量编辑](docs/screenshots/players.png)

### 2. 导入或编辑战术

在“战术板”中分别设置主队和客队：

- 点击“导入主队／客队比赛战术 FMF”，载入已有战术。
- 分别设置“有球阶段”和“无球阶段”，两阶段共用同一套首发。
- 拖动球衣交换球员时，角色、职责和个人指令留在原位置。拖到空位如需调整不兼容的设置，会先提示确认。
- 调整球队心态、传球、逼抢等球队指令。
- 在“定位球与职责”页面单独设置或导入定位球方案。
- 客队战术池：在池页面直接导入本机 FMF 战术，或从「存档战术」页面一键导入当前联赛对手预设；在底栏开启随机模式后，每场按权重抽取一套客队战术。

导入后可以继续修改。主队、客队和定位球各自有明确的编辑入口。启用客队战术池时，可以统一客队全部球员的能力属性，默认界面值 15，可配置；首发球员按抽中战术的对应位置获得最高位置熟练度。抽签由任务种子决定，同一实验内可复现。

### 3. 运行比赛

在底部填写起始种子、每方案场数和并行数，点击“运行比赛”。第一次先跑几场确认设置，再增加场数。

| 设置 | 用途 |
| --- | --- |
| 起始种子 | 指定这批比赛的随机输入，方便保存和复查 |
| 每方案场数 | 每套战术分别跑多少场 |
| 并行数 | 同时运行多少路比赛，按本机性能选择 |
| 快速模式 | 计算完整比赛，保存比分与球队统计，减少球员事件明细采集 |
| 完整模式 | 同时采集并核对射手、助攻和红黄牌等球员事件 |

**快速模式同样运行详细整场比赛。** 两种模式的区别在于结果明细的采集与核验范围。

### 4. 查看结果

进入“实验结果”，查看批次汇总、场均数据和逐场记录。完整模式还可查看进球与球员事件，逐场结果可以导出为 CSV。

有效场数和失败场次分别展示，汇总统计采用通过校验的完整比赛。

![战术对比与原版球队统计](docs/screenshots/results.png)

示例：两套方案各运行 6 场，展示战术对比、xG、射门、控球与传球统计。

## 用一次对比判断改动有没有效果

例如，你想测试“提高逼抢强度”是否适合当前阵容：

1. 载入原战术，确认球员、首发、对手和定位球，保存为对照战术。
2. 提高逼抢强度，保留其余设置。
3. 勾选“与已保存战术对比”，选择种子和每方案场数，开始推演。
4. 比较两套战术的进失球、xG、射门和控球变化。
5. 换一组种子、换一个对手，或者交换主客场，再看变化是否稳定。

例如，每方案设置 100 场，对照战术和本次战术就各跑 100 场，共 200 场。

对照保存的是当时的完整方案。每次围绕一个问题调整设置，更容易看清变化来自哪里。

## 怎样读结果？

| 想了解什么 | 结合哪些数据看 |
| --- | --- |
| 进攻是否改善 | 进球、xG、射门与射正 |
| 防守是否改善 | 对手的进球、xG、射门与射正 |
| 比赛风格怎样变化 | 控球率、传球次数和成功传球 |
| 优势是否稳定 | 多组种子、不同对手和主客场下的表现 |

把指标和你的战术目标放在一起看。例如，提高控球后，继续观察是否创造了更多、更好的射门机会。

### 实验的开赛条件

双方全名单统一使用：体能和比赛状态 100%、累积疲劳 0、士气 20/20、球队磨合 80、俱乐部磨合 100。比赛开始后，状态随比赛正常变化。

这样可以集中比较球员和战术设置。应用到自己的赛季时，再结合实际疲劳、士气、磨合和伤病安排使用。

### 战术执行力实验

打开「战术执行力实验」可分别设置双方的战术理解、教练认可和对手情报，各项为 0–100。球员能力贡献由原生代码按每名球员的 CA 和两阶段角色适配计算。此选项默认关闭，存档里的实际执行力尚未接入。

随机客队战术池支持与实验战术执行力同时启用，三项手动分数沿用双方设置，能力贡献按当前客队球员的 CA 和抽中战术的双阶段角色由原生引擎计算。执行力模式每场独立运行，速度会比普通复用模式慢。战术池更换战术，沿用当前客队名单，暂不能与电脑生成战术同时启用。

## 保存你的实验

- **完整方案 JSON**：保存双方球员和配置，下次通过“打开完整方案 JSON”继续。
- **比赛战术 FMF**：导出选中球队的比赛战术；定位球在对应页面单独导出。
- **逐场 CSV**：保存实验结果，方便记录、制表和比较。
- **实验历史**：支持命名、搜索、重命名和删除。确认删除会移除该实验的本地结果与日志。
- **本地结果目录**：桌面版托盘菜单可以打开结果目录，也可以从托盘退出程序。
